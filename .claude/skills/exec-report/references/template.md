## 표현 바꾸기 대조표

기술 문서의 표현을 그대로 쓰지 않는다.

| 기술 문서 | 보고서 |
|---|---|
| bushy 트리 / left-deep 트리 | 균형 잡힌 순서 / 단순한 일렬 순서 |
| 전수 열거(DP) | 가능한 모든 조합을 다 따져봄 |
| 휴리스틱 | 간이 방식 |
| Cascades / memo / 룰셋 | (쓰지 않는다. "처리 경로" 정도로 우회) |
| 카디널리티 추정 | 데이터 건수 예측 |
| 푸시다운 | 조건을 앞단으로 내려보냄 |
| 브로드캐스트 / 셔플 | 작은 쪽을 복사해 나눠줌 / 양쪽을 다시 나눔 |
| 세션 변수 / 시스템 속성 | 설정값 |
| 옵티마이저 | (주어를 "엔진"으로 바꾼다) |

**불가피하게 전문용어를 써야 하면 첫 등장에 한 줄 설명을 붙인다.** 두 번째부터는 그냥 쓴다.
